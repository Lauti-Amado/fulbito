# ⚽ Investigación de Mercado

Esta carpeta reúne toda la investigación realizada durante la etapa de análisis de mercado de **Fulbito**.

El objetivo de esta fase fue comprender cómo resuelven actualmente los grupos de fútbol amateur la organización de sus partidos, identificar las fortalezas y debilidades de las soluciones existentes y detectar oportunidades para diferenciar el producto.

# Objetivo de esta etapa

Esta investigación permitió validar que existe una oportunidad para una aplicación enfocada exclusivamente en el fútbol amateur de grupos privados, priorizando el historial, las estadísticas y la simplicidad por encima de la organización de torneos o la búsqueda de jugadores.

Los documentos de esta carpeta servirán como base para definir los requisitos funcionales y las decisiones de diseño del proyecto.

---

> **Cada competidor aporta un aprendizaje. Fulbito nace de combinar lo mejor de todos sin copiar a ninguno.**
